# Changelog

All notable changes to the **Sitecore XM Cloud Readiness Toolkit** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-17

### Added
- **README.md:** Project overview, intended audience, scope boundaries, repository structure, quick-start workflow, Red/Amber/Green (RAG) scoring rubric, and roadmap.
- **LICENSE & CONTRIBUTING.md:** MIT open-source license and community contribution guidelines emphasizing confidentiality, neutrality, and fact verification.
- **docs/xm-cloud-readiness-checklist.md:** 35 structured assessment questions across 15 technical and operational domains, each detailing evidence to collect, RAG criteria, migration implications, and recommended next actions.
- **docs/architecture-decision-matrix.md:** Retain, Modernize, and Replace comparison matrix covering 12 core architectural domains (rendering, edge delivery, search, Digital Asset Management [DAM], personalization, forms, identity, hosting, CI/CD, and integrations).
- **docs/migration-assessment-template.md:** Standardized discovery report template including executive summary, current landscape, assumptions, findings, domain heat map, dependencies, migration waves, and governance sign-offs.
- **docs/integration-inventory-template.md:** Structured catalog for auditing inbound/outbound integrations, protocols, authentication, data classification, SLAs, and XM Cloud dispositions.
- **docs/risk-register-template.md:** Risk tracking matrix with likelihood/impact scoring, mitigation strategies, contingencies, triggers, and ownership.
- **examples/sample-retail-site-assessment.md:** End-to-end worked example demonstrating a completed discovery assessment for a fictional multilingual retail organization.
